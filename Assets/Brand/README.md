# HYPNIX brand assets

HYPNIX is the official application and product name.

Brand line: **Relax. Have fun. Be cool.** Lead with atmosphere, enjoying music
through live visuals, and personal desktop style. Use the
[positioning and sales strategy](../../docs/MARKETING_STRATEGY.md) for sales copy.

Files:

- `hypnix-icon-v2.png`: current high-impact application mark used by the WPF shell.
- `hypnix-v2.ico`: current multi-resolution Windows icon used by the executable, window, and shortcuts.
- `hypnix-tray-white.png` and `hypnix-tray-white.ico`: transparent, tightly cropped white monogram used only
  in the Windows notification area, optimized for 16-48 px visibility.
- `hypnix-icon.png` and `hypnix.ico`: retained version 1 assets for brand history and rollback.
- `hypnix-icon-chroma-source.png`: retained generation/intermediate source for audit and future reprocessing.

Identity rules:

- Preserve the flowing looped `H` geometry and layered cyan, violet, magenta, coral, and gold ribbons.
- Use the monogram without the wordmark for small icons.
- Notification-area artwork must have real transparency, no square background, minimal clear space, and a
  high-contrast monochrome silhouette. Do not reuse the padded full-color application artwork in the tray.
- Use the uppercase wordmark `HYPNIX`; do not use the former product-facing name `Animated Wallpaper`.
- Keep clear space around the mark and never stretch it non-uniformly.
- Dark UI is the primary application context; the transparent mark must remain usable on light surfaces.
- Store/source packages must keep the original brand assets in this directory and derive sizes from them.

Version 2 was produced with the built-in image-generation workflow from the high-impact logo references
supplied by the product owner and validated visually before use. Version 1 used the same workflow followed
by local chroma-key processing.
