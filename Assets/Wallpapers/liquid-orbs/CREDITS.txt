Liquid Orbs - original HYPNIX wallpaper.

This is an original, clean-room HYPNIX implementation. It renders liquid metaballs
using generic, non-copyrightable techniques (signed-distance smooth-union
metaballs, perspective raymarching, tetrahedral normals, linear-light diffuse +
Blinn-Phong specular, Schlick fresnel, a procedural gradient environment
reflection, cheap SDF ambient occlusion and a filmic tonemap).

Per-orb motion is generated by HYPNIX with our own hash (speed, phase, radius).
No third-party shader code is used and all shading parameters were authored by
HYPNIX. Any earlier externally supplied snippet has been fully replaced.
